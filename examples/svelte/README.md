# Svelte example

A standalone Vite project (it is not part of the root package). From the repository root, build the library first, then:

```bash
npm run build
cd examples/svelte
npm install
npm run dev
```

`sayshape` is linked from `../..` (`file:../..`). See [`docs/integration/svelte.md`](../../docs/integration/svelte.md).
